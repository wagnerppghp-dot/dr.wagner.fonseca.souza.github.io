# Portfólio profissional — Wagner Fonseca Souza

Site pessoal desenvolvido em HTML, CSS e JavaScript para apresentar trajetória, formação, competências e projetos nas áreas de Tecnologia, História Pública e Direito.

## Tecnologias

- HTML5 semântico e dados estruturados Schema.org
- CSS responsivo, acessível e com identidade visual própria
- JavaScript sem dependências para menu, animações, filtros e interação

## Publicação

O site é publicado com GitHub Pages a partir da branch `main` e pasta raiz.
